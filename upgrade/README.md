# 轻量升级源码

`controller.sh.in`：发现已有 R3.1/R3.2 部署，校验容器归属和镜像 ID，准备候选目录，切换、验收并在失败时回滚。支持原服务运行或停止状态，不强制先启动旧服务。

`installer.py`：对全部内嵌内容和旧目录复制素材校验 SHA-256，再写入全新目录。模型路径、缓存路径和镜像 ID 通过显式参数传入，不依赖 sudo 保留环境变量。不会复制模型权重。

`payload.json`：每个文本源码文件的 Base64、SHA-256、权限，以及复用旧测试素材的摘要。Base64 是编码方式，不是加密。这里的脚本变体针对复用旧镜像，根目录脚本针对完整 R3.3 镜像，两者配置一致。

`build_command.py`：从以上源码重新生成可读 `upgrade-r33.sh` 和单行命令 `base64-r3.3.cmd`；所有内容完整解码并验证 SHA-256 后才执行。

```bash
python3 upgrade/build_command.py
cmp base64-r3.3.cmd upgrade/base64-r3.3.cmd
```

执行升级时请把根目录的 `base64-r3.3.cmd` 放到原部署目录后运行，不要在源码仓库中运行。升级会重启服务、重新建立内存前缀缓存，并复用磁盘编译缓存；不修改 New API 设置。原部署目录和镜像保留用于回滚。
