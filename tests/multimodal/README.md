# 多模态验收素材

使用现有经过 SHA256 固定的合成图片。根目录执行 `bash multimodal_test.sh full`。

12 个用例覆盖 OCR、表格、倾斜 OCR、图表、空间计数、多图、缺失信息、有序图片帧、多轮、流式、工具往返和换图控制。`cases.json` 固定图片 SHA256 和预期答案；工具最终回复要求明确的 JSON 格式，保留工具名称、参数和第二轮结果的严格校验。

素材中的 GLM 名称及 8006 端口是需要读取的图片内容；R3.3 的请求模型始终为 `DeepSeek-V4-Flash`，服务端口 8005。

`sequence.mp4` 是参考素材，启用的序列用例使用有序图片帧。测试不是原生视频能力或通用模型质量证明。
